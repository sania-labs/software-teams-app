# Software Teams

AI-balanced task management, built for developers.

Software Teams is a lightweight Kanban board for small dev teams, with
built-in AI that suggests task owners, writes clear tasks from rough notes,
and auto-generates weekly progress summaries — without the complexity (or
price) of Jira or Asana.

## Progress
- [Sprint 0 — Research & Proposal](./sprint-0/README.md)

## Why
Most task tools are built for enterprise teams. Small teams end up paying
for (and learning) features they'll never use, with no visibility into who
on the team is overloaded. Software Teams fixes that with two roles,
zero setup, and AI that explains its suggestions instead of just making them.

## Features
- Kanban board with a live workload chart
- AI Smart Auto-Assign (suggests + explains task ownership)
- AI Task Writer (rough note → clear task)
- AI Weekly Summary (auto-generated progress recap)

## Tech Stack
React Native · Expo · TypeScript · Firebase Auth · Cloud Firestore ·
Cloud Functions · GitHub Actions
